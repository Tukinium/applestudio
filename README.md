# 🍎 アップルスタジオ / AppleStudio

VRChatグループ「アップルスタジオ（AppleStudio）」の公式Webページです。

## 内容
- メンバー紹介
- 公式YouTubeチャンネルへのリンク
- 公式X（旧Twitter）へのリンク

## 構成
| ファイル | 役割 |
|----------|------|
| `index.html` | ページ本体 |
| `style.css`  | デザイン（可愛い系・リンゴモチーフ） |

## 編集のしかた
- **メンバーを追加**：`index.html` の `member-card` を必要な数だけコピーして、名前とひとことを書き換えます。
- **リンクを設定**：`index.html` の「公式リンク」内、YouTube・X の `href="#"` を実際のURLに差し替えます。
